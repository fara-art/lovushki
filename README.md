# Восемь ловушек

Браузерная игра о безопасности в сети и в жизни: мошенники, фишинг, вербовка. Задания подбираются под возраст игрока.

- `site/` — статический сайт:
  - `index.html` — лендинг
  - `play/` — игра «Восемь ловушек» (один HTML-файл, PWA)
  - `udar/` — вторая игра «Двойной удар» (мессенджер-схемы)
  - `teachers/` — материалы для урока (памятка, текст выступления, вопросы)
  - `assets/` — шрифты, скриншоты, промо-видео
- `deploy/` — выкладка на Ubuntu/Debian:
  - `setup.sh` — nginx + сайт + служба отзывов (повторный запуск = обновление)
  - `https.sh` — сертификат Let's Encrypt для домена
  - `feedback.py` — приём отзывов и списка игроков (stdlib Python, 127.0.0.1:8787), админка `/admin/` с вкладками «Отзывы» и «Кто играл»
  - `feedback-setup.sh` — пароль `/admin/` и почта для отзывов
  - `indexnow.sh` — уведомление Яндекса/Bing об обновлении
  - `nginx.conf`, `nginx-ip.conf`, `nginx-headers.conf` — конфиги сайта и общий список заголовков защиты

## Выкладка

```sh
tar czf site.tar.gz site deploy
scp site.tar.gz root@СЕРВЕР:/root/
ssh root@СЕРВЕР 'cd /root && tar xzf site.tar.gz && sh deploy/setup.sh'
```

## Для школ

- В форме отзыва и при создании аккаунта в обеих играх есть «Я ученик»: имя, фамилия и класс.
- Обе игры сообщают серверу, кто играет и сколько прошёл (`POST /api/players`).
  Не дошло (нет интернета) — ждёт в браузере и отправляется позже.
- `/admin/igroki` — «Кто играл»: поиск по фамилии, фильтр по классу и игре, выгрузка класса в Excel.
- Сертификат есть в обеих играх: в «Восьми ловушках» — после прохождения района,
  в «Двойном ударе» — когда пройдены все уровни. Ученику на сертификате пишется класс.
- На сервере: `python3 /opt/lovushki/feedback.py --players` — тот же список в консоли.

## Безопасность

- **Заголовки защиты** (`deploy/nginx-headers.conf`): Content-Security-Policy (код, шрифты и запросы — только
  со своего сайта), запрет вставки сайта в чужие страницы, HSTS, Permissions-Policy, nosniff.
- **Админка**: только через https, не больше 30 запросов в минуту с адреса, пароль от 10 символов,
  хранится хэшем SHA-512. Скрипт страницы разрешён одноразовой меткой (nonce), удаление — только
  запросом с самой страницы.
- **Данные учеников** (`/var/lib/lovushki`): папку и файлы читает только служба и root; адреса посетителей
  не сохраняются. Служба отзывов работает в песочнице systemd.
- **Приём данных**: только `application/json` (чужой сайт не отправит отзыв из браузера посетителя),
  лимиты в nginx и в `feedback.py`, суточный лимит новых аккаунтов с одного адреса.
- Чего код не решает: обновления и вход на сам сервер, двухфакторная защита аккаунта GitHub
  (выкладка берёт код из репозитория и запускает его от root), согласие родителей на хранение
  фамилий и классов. Цифры в «Кто играл» присылает браузер игрока — технически подкованный
  ученик может их подделать.
- После обновления стоит заново задать пароль админки, чтобы он сохранился новым хэшем:
  `sh deploy/feedback-setup.sh`.
